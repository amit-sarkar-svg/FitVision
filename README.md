# FitVision

Interactive Multimedia Fitness Learning Platform — Frontend UI Foundation

## Tech Stack

- React 18 + Vite
- Tailwind CSS
- React Router
- Lucide React (icons)
- Framer Motion (animations)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Key Routes

| Route | Description |
|-------|-------------|
| `/dashboard` | Dashboard placeholder |
| `/exercises` | Exercise library |
| `/exercises/dumbbell-bench-press` | **Full Exercise Detail page** |
| `/workout-plans` | Workout plans placeholder |
| `/diet-nutrition` | Diet & nutrition placeholder |
| `/bmi` | BMI calculator placeholder |
| `/progress` | Progress tracker placeholder |
| `/favorites` | Favorites placeholder |
| `/tips` | Tips & articles placeholder |
| `/settings` | Settings placeholder |
